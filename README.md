# Open Reform

Proven ideas from around the world, scored and proposed for Pakistan.

Open Reform is a YouTube channel and this public repository. For each reform we look at something that already works in another country, write a proposal for doing it in Pakistan, score it, and make a short video. Everything here is public, permanently.

## See the reforms

Download or clone the repo and double-click **`index.html`**. No server, no install. It lists every reform, lets you filter by sector and by score, and opens each proposal when you click it.

## How a reform is scored

Every reform is rated **low / medium / high** on five metrics:

| Metric | Question | Good is |
|---|---|---|
| Impact | How much better does life get, and for how many people? | high |
| Cost | How much public money does it need? | low |
| Difficulty | How hard is it to build and run? | low |
| Resistance | How much political and vested-interest pushback? | low |
| Time | How long before citizens see results? | low |

These combine into a score out of 100. The best reforms are high impact, cheap, easy, unopposed and fast. Details: [.docs/metrics.md](.docs/metrics.md).

## What is in the repo

```
index.html              the dashboard (double-click)
update.cmd              refresh the dashboard data (double-click, Windows)
reforms/
  001-short-name/
    proposal.md         the written proposal, with ratings at the top
    presentation.md     the video: one image and one narration per slide
    images/             AI-generated images used in the video
  _template/            starting point for a new reform
data/                   generated by the CLI, read by index.html
.cli/reforms.mjs        the CLI that generates data/
.docs/                  how the project works
```

## Add or edit a reform

Needs [Node.js](https://nodejs.org) 18 or newer.

```bash
node .cli/reforms.mjs new "Title of the reform"
```

Edit the files in the new folder, then rebuild the dashboard data:

```bash
node .cli/reforms.mjs build
```

Full workflow: [.docs/workflow.md](.docs/workflow.md).

## Contribute

Found a wrong number, a better example, or a reason an idea would fail in Pakistan? Open an issue or a pull request. Every figure in a proposal must link to a source.
